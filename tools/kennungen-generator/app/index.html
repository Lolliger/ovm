OMUN Kennungen

Erzeugt persönliche Kennungen für die Anmeldung. Namen bleiben auf diesem Computer – an die Website gehen nur die Kennungen.

So geht's

  1. Einmalig: unten die Verbindung zur Website einrichten (Schlüssel aus dem Admin unter Kennungen).
  2. Namensliste einfügen (eine Person pro Zeile) oder nur eine Anzahl angeben und Kennungen erzeugen.
  3. Kennung und Name stehen danach in der Liste OMUN-Kennungen.csv auf dem Schreibtisch, und die Kennungen sind auf der Website sofort freigeschaltet.
  4. Jeder Person ihre Kennung geben (z. B. mit „Zettel drucken“).

Mehrere Spalten aus Excel (z. B. Name und Schule) bleiben zusammen in einer Zeile erhalten.
