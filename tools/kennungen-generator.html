Kennungen-Generator

Erzeugt persönliche Kennungen für die OMUN-Anmeldung. Läuft nur in diesem Browser – nichts wird hochgeladen.

So geht's

  1. Namensliste einfügen (eine Person pro Zeile) oder nur eine Anzahl angeben.
  2. „Liste mit Namen“ herunterladen und bei euch speichern – sie kommt nie auf die Website.
  3. „Nur Kennungen“ herunterladen und im Admin unter Kennungen hochladen.
  4. Jeder Person ihre Kennung geben (z. B. mit „Zettel drucken“).

Mehrere Spalten aus Excel (z. B. Name und Schule) bleiben zusammen in einer Zeile erhalten.
